## 文件说明

| 文件 | 作用 |
| --- | --- |
| `sticker.html` | 可编辑 HTML 源，固定 1080×1920 画布，全部文案为原生 DOM 文本，可直接改字、改色、改坐标 |
| `compose.py` | Pillow 确定性渲染脚本，与 HTML 同一套几何与配色，本地一键导出成品 PNG |
| `assets/background.jpg` | 实景背景图（需自行放入；当前仓库不附带用户实景照片） |
| `output/sticker.png` | 脚本导出的成品图 |

## 本地渲染

1. 将实景照片放到 `assets/background.jpg`；
2. 确认本机已安装 Python 3 与 Pillow（`pip install pillow`）；
3. 运行：

```powershell
python compose.py
```

成品输出到 `output/sticker.png`。

## 设计约定

- 画幅：1080×1920（9:16）；关键信息避开顶部 8%、底部 20%、右侧 12–15% 安全区。
- 卡片家族：暖白 `#FDF8EE`、32px 大圆角、1px 哑金细边、单层柔和弥散投影；不使用嵌套内卡、徽章、流苏、票根、卷轴、折扇等装饰造型。
- 主标题：粗体金色纵向渐变 + 暗金厚度侧面 + 柔化落地投影。
- 票档：红底胶囊标签置于价格上方；现价字号 ≥ 标签字号 2 倍，正红加粗。
- 配色：红 `#9E241F` / `#B02020`，哑金 `#D9B872` / `#B98A3E`，暖白 `#FDF8EE`，正文深棕 `#3A2418`。

## 修改方式

- 改文字：直接编辑 `sticker.html` 对应文本节点，或 `compose.py` 中对应 `draw.text` / `draw_tracked` 文案后重新渲染。
- 改颜色：统一修改两个文件顶部配色常量 / 行内样式。
- 改位置：以 1080×1920 画布为基准调整卡片与文字坐标，保持左右卡片对称、价格为画面最大字号。
